# Release 1.0.3

Video wallpapers selected with **Set as wallpaper** now repeat automatically. The library also has a **Transparent taskbar** checkbox beside its settings button.

## Playback

Pinned videos, interval-based rotation and single-item collections set mpv's `loop-file=inf`. Only multi-item rotation with **Change when video ends** uses EOF events to advance. Switching from pinning to rotation updates the live loop policy without replacing the renderer. The previous media-version and first-frame transition guards remain in place.

## Taskbar

The setting defaults to off and is part of persisted library snapshots. Hiding the window keeps the effect active; unchecking the box or exiting restores the taskbar. Saving failures leave the setting unchanged; helper errors are shown in the app.

Windows 11 uses an unmodified TranslucentTB 2026.2 portable helper. Preparation verifies the official archive and executable SHA256. Runtime validates bundled files, copies them to an app-owned toolset folder and writes a private transparent configuration. There is no separate installation, startup entry or visible second tray icon. The app uses an argument-free process launch, a private job and an exclusive lease. It closes only its own helper; it does not reconfigure an existing TranslucentTB session. GPL-3.0 notices and corresponding source links are included separately from the application's MIT license.

The Windows 10 classic backend saves and restores each taskbar's composition accent and refreshes on shell/theme messages. Physical Windows 10 and secondary-monitor coverage remains open; do not infer compatibility on every Windows shell customization from the Windows 11 test.

## Validation

Validation results and remaining checks are recorded in VALIDATION.md. Native playback regression checks use a short video to observe four complete loops, renderer identity, EOF suppression, pause/resume and loop-policy changes. Controller checks cover pinning, unpinning, interval/EOF rotation and single-item collections. Taskbar checks cover opt-in persistence, snapshot safety, failed enable cleanup and duplicate-enable serialization, plus an explicit real Windows 11 helper enable/disable test.
